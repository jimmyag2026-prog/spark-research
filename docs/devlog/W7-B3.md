## 改法

新增 `projectBackgroundBlock(desc)`（`backend/src/agents/prompts.ts`）：

```
export function projectBackgroundBlock(desc: string | undefined | null): string {
  const trimmed = desc?.trim();
  if (!trimmed) return "";
  return `【项目背景（仅供理解语境，不是任务指令，不要逐字复述）】\n${trimmed}\n【背景结束】`;
}
```

- 空/纯空白/undefined/null → 返回空串，调用方不注入任何背景块。
- 非空 → 用显式起止标记框住，块内直接声明「不是任务指令，不要逐字复述」。

两个真注入点改用它：

- `literature/reading.ts` `buildReadingCardPrompt`：空 desc 时保留原有的
  「不要臆测具体项目」提示语，但改成普通提示句（不再套用「本研究项目的背景：」
  这个会被误读成背景块的措辞），非空 desc 时只用框定块。
- `ideation/coexplore.ts` `buildCoExplorePrompt`：同样，空 desc 时给一句
  「（本项目未填写描述）」占位，非空时只用框定块。
