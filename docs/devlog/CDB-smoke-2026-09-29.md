# 跨领域桥接报告

## 问题

我想用蛋白语言模型的注意力图直接预测别构位点

已知死路：序列保守性打分；分子动力学穷举

## 结构签名（已剥离领域术语）

对象：由离散符号组成的长序列；一个在大量同类序列上训练出来的序列处理模型；模型内部各位置之间的成对影响权重；序列上少数关键位置，其状态改变会远程改变另一功能区域的行为；被远程影响的功能区域或执行单元；对关键位置进行扰动后观测到的功能变化标签
关系：序列的符号排列与位置索引决定模型内部成对影响权重的模式；某些关键位置与远端功能区域之间存在因果耦合：改变前者状态会改变后者行为，中间可能经过若干中介位置；模型内部的成对影响权重可能在关键位置与远端功能区域之间呈现非局部关联；功能变化标签与关键位置身份相关，但标签通常只覆盖少量已知位置，不直接给出全部关键位置
动力学：模型处理序列时按位置逐步更新内部状态，早期局部信息逐步汇总成全局表示；成对影响权重随输入序列变化而非固定结构；预测流程可迭代为：从当前权重模式提出候选位置，再通过扰动与功能读数更新候选排序。
约束：只有序列和模型内部量可大规模、低成本获得；对真实系统做功能扰动测量昂贵、稀疏且有噪声；关键位置可能由多个位置协同决定，不能假设彼此独立；远程耦合可能经过中介，直接相关不等于因果；训练序列与评估序列若高度相似，会造成虚假性能；关键位置在整条序列中占比很低，正负样本极不平衡
目标：仅凭序列处理模型内部的成对影响权重，判定序列上哪些位置属于“状态改变会远程影响另一功能区域”的关键位置，并尽可能提高候选排序或分类的准确率与因果有效性。
可观测量：序列符号及位置索引；模型内部成对影响权重的数值与空间模式；对候选位置施加扰动后远端功能读数的变化；已标注的关键位置集合（若存在）；模型输出的候选位置分数或排序

### #1 实验设计/筛选统计（高维稀疏活跃因子筛选与远程响应） · Elo 1046（3胜 0负 0平）

**假设**：在控制序列相似性和位置频率后，按成对影响权重经FDR/稳定性选择得到的关键位置集合，其远端功能扰动效应显著高于随机同规模位置集合；若在留出不相似序列上该富集消失或Spearman≤0，则命题为假。

**机制**：把序列位置视为高维稀疏可操纵因子，把模型内部成对影响权重视为低成本代理读数，把昂贵远端扰动读数视为确认响应；用部分因子、序贯分支和组检验做候选分组，用FDR/稳定性选择控制假阳性，用中介路径组检验处理非局部耦合，并迭代更新候选排序。

**映射表**（◆ 承重 / ◇ 装饰）：

  ◆ 高维筛选实验中的因子（可操纵输入变量） → 序列中的位置索引及该位置符号状态（把每个位置视为一个因子，改变该位置符号等价于改变因子水平；候选关键位置就是待筛活跃因子。）
  ◆ 低成本代理响应或设计矩阵快速读数 → 模型内部成对影响权重在大量序列上的数值与空间模式（成对影响权重是可大规模获得、便宜的代理响应，用于第一轮位置级排序。）
  ◆ 昂贵确认试验或物理扰动 → 对候选位置施加扰动后远端功能读数的变化（昂贵、稀疏、带噪的远端读数提供因果确认标签，用于校准筛选和FDR。）
  ◆ 主效应与交互效应的分解 → 位置对远端区域的边际影响与位置间成对影响/中介耦合（远端效应可能由多个位置协同并经中介传递；只筛独立主效应会把中介或联合活跃位置排错。）
  ◆ 效应稀疏性 → 关键位置在整条序列中占比极低且正负样本不平衡（稀疏性决定使用筛选、阈值化、FDR，而非全位置穷举检验。）
  ◆ 部分因子设计的别名/混杂结构 → 训练-评估序列相似、位置频率、共同上下文造成的非局部伪关联（低成本权重中的非局部关联可能被混杂；必须用留出不相似序列、分层或随机化打破。）
  ◆ 序贯分支与组检验 → 从权重模式先提出候选位置组，再分组扰动并拆分阳性组（在扰动昂贵且活跃位置稀疏时，先测组后拆单点可降低确认成本并迭代更新排序。）
  ◇ D-最优或自适应抽样 → 下一步选择哪些位置或上下文做昂贵扰动以最大化信息（依据已有权重和噪声模型选择确认点，提高候选排序与因果有效性。）
  ◇ FDR/BH或稳定性选择 → 对大量候选位置筛选后的错误率控制（控制假阳性，使top-k候选集合可信。）
  ◆ 响应面与中介分析 → 关键位置到远端功能区域之间的中介位置路径（直接相关不等于因果；需要阻断或调整中介来检验远程耦合。）

**常规骨架**：两阶段筛选-确认：先用成对影响权重做低成本代理，计算位置级边际分数并用稳定性选择或Lasso排序；用BH-FDR控制候选假发现；再对top候选组做少量随机化、重复的扰动-远端读数确认；用留出不相似序列分层复核。；效应稀疏下的序贯分支/组检验：按权重模式将位置分块，先对块施加聚合扰动或模型内组消融并读远端功能；阳性块二分拆解直到单位置；每步用序贯检验或FDR更新停止规则与候选排序。；部分因子/Plackett-Burman加foldover去别名：把候选位置当因子，用低成本权重定义活动范围，运行小规模PB或foldover扰动设计，估计主效应并与交互/中介效应分离；再用D-最优补点确认。
**非典型注入**：只加一处：把成对影响权重中的高权重边不当作直接效应，而当作可能的中介路径；将序贯组检验从筛因子改为筛中介路径——先分组阻断或干预中介位置，再看关键位置到远端功能的效应是否被解释掉，从而用中介筛查代替主效应筛查。
**廉价伪证**：下周纯计算伪证：取留出且与训练序列相似度低的一组序列，用现有模型计算候选分数；对候选位置做模型内消融或激活，记录远端层表示变化范数作为廉价代理读数；随机抽同规模位置作零分布。若在留出集上候选分数与远端代理读数的Spearman≤0，或FDR选出的top-k位置相对随机位置的代理效应富集倍数≤1（或95%区间跨1），则判迁移失败；若真实扰动标签可用，则precision@k不高于随机即错。

### #2 控制理论 / 系统辨识（可控性与可观性分析、最优实验设计） · Elo 1017（2胜 1负 0平）

**假设**：若关键位置确实是稀疏输入通道，则仅由模型内部成对影响权重构造的经验可控 Gramian 的对角排序，应与真实扰动–远端读数灵敏度排序呈 Spearman ρ ≥ 0.5 的正相关，且植入/已标注的关键位置应落入该排序的前 10%；否则本迁移的承重映射不成立。

**机制**：把序列处理过程读作一条受控离散时间轨迹：位置索引就是时间步，少数关键位置是稀疏输入通道，被远程影响的功能区域是输出通道。'某位置是否关键'于是等价于'该输入通道到该输出通道的可控度是否显著'，可由经验可控/可观 Gramian、PBH 检验与模态参与因子给出一个可排序、可做实验设计度量的标量，从而把'找关键位置'变成稀疏执行器选择与 D-最优实验设计问题。

**映射表**（◆ 承重 / ◇ 装饰）：

  ◆ 离散时间受控状态更新 x_{k+1}=f(x_k,u_k)，位置索引 k 即时间步，前向传播是一条受控轨迹 → 模型按位置逐步更新内部状态、早期局部信息逐步汇总为全局表示（位置↔时间步，前向计算↔轨迹演化；因果方向被固定为'早位置影响晚位置'）
  ◆ 在位置 k 施加的稀疏输入通道 u_k（脉冲/阶跃输入） → 序列上少数关键位置：改变其状态会远程改变另一功能区域的行为（扰动关键位置=驱动一个输入通道；'关键'=该通道对目标输出有非零增益）
  ◆ 远端输出通道 y=h(x_N)，即被测量本身有确定定义、可重复读数 → 被远程影响的功能区域/执行单元，以及对关键位置扰动后观测到的功能变化标签（功能读数=输出方程；labels=带噪的量测样本）
  ◆ 脉冲响应/马尔可夫参数 ∂y/∂u_k，以及经验可控 Gramian W_c(k)=Σ_j A^j B_k B_k^T (A^T)^j 的对角元 → 对候选位置施加扰动后远端功能读数的变化幅度（两者是同一个量：输入通道到输出的灵敏度）
  ◇ 线性化雅可比 A_k=∂f/∂x（工程上常用有限差分替代） → 模型内部各位置之间的成对影响权重（影响权重被读作局部雅可比的近似（仅此近似，不做等价断言））
  ◇ 可控/可观 Gramian 的谱（特征值、秩、Hankel 奇异值）与 PBH 特征值检验 → 模型输出的候选位置分数或排序（排序统计量↔分数；低可控度方向↔可判为无关的位置）
  ◇ 模态参与因子：把 Gramian 投影到 A 的主导特征模上的分量 → 关键位置与远端功能区域之间的非局部关联模式（长程、非局部的耦合被解释为低阶主导模态的参与）
  ◇ 多输入系统的 Gramian 非对角项：通道之间不可加、存在协同 → 关键位置可能由多个位置协同决定，不能假设彼此独立（协同约束↔Gramian 的非对角结构；禁止把单点排序直接相加）
  ◇ 子模/凸松弛下的稀疏执行器选择目标（log det、trace、最小特征值），以及 D-最优/互信息实验设计 → 在标签稀疏、正负样本极不平衡、扰动昂贵的前提下提高候选排序或分类的准确率与因果有效性（实验预算约束↔只能做少量昂贵扰动；设计准则↔排序/分类目标）

**常规骨架**：经验 Gramian + 脉冲响应筛选（Moore 系）：对每个候选位置施加小扰动（或对状态做前向有限差分），记录远端读数变化，累加构造经验可控度指标，按对目标输出的可控度排序；再用主导模态的模态参与因子对排序做二次加权——这是线性系统模型降阶/传感器布置里用了四十年的常规流程。；对偶侧的可观性路线：把远端功能读数当作量测通道，沿位置方向做线性化卡尔曼滤波，用新息协方差与可观 Gramian（或 PBH 检验）判断'哪些位置的状态能被远端输出看见'，最后取'可控且可观'的交集——因为只有同时可控且可观的位置才真正承重。；稀疏执行器选择：以 Gramian 的标量函数（log det / trace / 最小特征值）为目标，在基数约束下用子模贪心或凸松弛选出 K 个位置，直接对应'关键位置占比极低'与'只能做少量昂贵扰动'两个约束。
**非典型注入**：把'哪些位置是关键'本身当作待辨识的稀疏二值参数，而不是把位置按可控度排序：扰动位置的选择改为对该二值参数做 D-最优/互信息实验设计（最大化扰动设计对 0/1 关键集的支持恢复信息），从而在极少次昂贵扰动下恢复整张关键位置图，而非只给出一个边际可控度排行榜。注意这是唯一一处非常规注入：它借用的是六十年前的经典最优实验设计（Kiefer/Fedorov），不是新发明，只是把它从'已知输入位置、选哪几个用'搬到'输入位置本身未知'。
**廉价伪证**：下周就能做：训练一个两层极小序列模型，在合成任务里植入一条已知的长程依赖（例如把位置 3 的 token 复制到位置 60 的输出），此时真关键位置由构造已知。然后用两种方式给所有位置排序：(a) 直接由模型内部成对影响权重构造经验 Gramian；(b) 对每个位置做有限差分扰动、记录远端读数变化构造 Gramian。判错条件：若 (a) 的前 10% 与植入位置交集为空，或 (a) 与 (b) 的排序 Spearman ρ < 0.3，则'内部影响权重≈局部雅可比'这条映射被证伪，只有 (b) 路线可保留。附带的线性性检查：把扰动幅度加倍，若远端读数变化超出约 2.2 倍（明显非线性/饱和），则 Gramian 本身在该工作点无效，本迁移必须改为分段线性化或仅用序信息，看到这一点也算错。

### #3 程序分析/软件可靠性 · Elo 983（1胜 2负 0平）

**假设**：若把成对影响权重阈值化为动态依赖边并从远端功能读数反向切片，则在相同远端读数预算下，切片内 top-k 候选的单位置扰动因果命中率至少是随机位置基线的 2 倍；若不超过，或在序列簇交叉验证后优势消失，则迁移失败。

**机制**：把序列模型视作可插桩程序，把位置间成对影响权重视作动态依赖边，把远端功能读数视作断言或失效症状。先按输入或输入簇对成对影响权重做阈值化，构建位置级动态依赖图；再从远端功能读数反向动态切片，得到候选关键位置；用稀疏关键位置标签做频谱故障定位可疑度排序；最后用 delta debugging 分组扰动，只花少量昂贵远端读数把候选缩小到最小因果集。非典型注入是用序列簇级交叉验证校准可疑度，阻断同模板重复序列造成的测试套件污染。

**映射表**（◆ 承重 / ◇ 装饰）：

  ◆ 动态执行轨迹：按执行顺序排列的指令或事件及其位置索引 → 长离散符号序列及其位置索引（执行顺序与位置索引是依赖传播的坐标系；序列位置对应程序点。）
  ◆ 动态依赖图：控制依赖、数据依赖，以及由覆盖次数或路径频率加权的边 → 模型内部各位置之间的成对影响权重（把边权重视为位置间影响强度，依赖图提供从远端读数反向到达关键位置的传播路径。）
  ◆ 故障语句或关键谓词：其状态或取值改变会经传播链导致远端失效 → 关键位置：其状态改变会远程改变另一功能区域行为（因果耦合通过中介节点传播；直接相邻不等于唯一路径。）
  ◆ 失效症状、断言或输出变量 → 被远程影响的功能区域或执行单元（作为反向切片的汇点，观测远端功能读数变化。）
  ◇ 测试结果标签：通过或失败，以及变异体杀死或存活 → 对关键位置扰动后观测到的功能变化标签（稀疏标签用于校准可疑度；只覆盖少量已知位置。）
  ◇ 动态切片或反向切片：从症状节点沿依赖边反向可达的语句集合 → 候选关键位置集合或排序（从远端功能读数反向收集位置，再按路径强度聚合排序。）
  ◇ 频谱可疑度公式，如 Ochiai 或 Tarantula → 模型输出的候选位置分数或排序（将位置在正负样本中的出现频率与影响权重结合，输出排序。）
  ◇ 输入相关的执行路径与覆盖谱 → 随输入序列变化的成对影响权重模式（不同输入产生不同依赖或覆盖，因此候选排序必须按输入或输入簇条件化。）

**常规骨架**：动态依赖图加反向切片：从远端功能区域读数节点出发，沿阈值化后的成对影响权重反向传播，按路径强度或到达概率聚合，得到候选关键位置集合。；频谱故障定位：把已知关键位置扰动标签当作失败或通过测试覆盖，用 Ochiai 或 Tarantula 类公式结合位置出现频率与影响权重，对候选位置打分排序。；delta debugging 或分组扰动最小化：对候选集合做二分或 ddmin 分组扰动，只调用昂贵远端功能读数，把候选缩小到最小因果位置集。；变异测试：对候选位置做单点或多点符号替换，按远端功能读数是否变化区分杀死与存活变异体，作为因果有效性过滤。
**非典型注入**：用序列簇级交叉验证校准可疑度：按序列模板或簇而非单条序列划分训练与评估，并在每个簇内重新计算影响权重与可疑度，防止高度相似训练序列重复覆盖同一位置造成虚假高可疑度；这是把软件可靠性里的测试套件污染控制注入到模型内部故障定位中。

### #4 统计物理（无序系统/自旋玻璃） · Elo 954（0胜 3负 0平）

**假设**：若在留出的稀疏扰动标签上，按推断 J 算出的远端响应 χ_iB 排序的 top-k 关键位置召回率不高于随机排序的 95% 置换上界，则本迁移的核心映射被证伪。

**机制**：将输入序列决定的内部成对影响权重视为淬火无序伊辛/Potts 模型的耦合矩阵 J_ij(x)，位置为自旋，远端功能区域为读出块 B；先用正则化逆伊辛重建 J 和场 h，再用信念传播/TAP/线性响应计算 χ_iB，按 χ_iB 与联合扰动响应排序关键位置。

**映射表**（◆ 承重 / ◇ 装饰）：

  ◆ 离散自旋 σ_i ∈ {±1}（或 Potts 态）及位置格点 i → 序列符号及位置索引（把序列每个位置粗粒化为一个自旋，位置索引即格点索引；符号与上下文决定其局域态。）
  ◆ 淬火无序成对耦合 J_ij(x)，每个输入序列 x 实现不同 → 模型内部各位置之间的成对影响权重（固定输入序列后，内部成对影响权重被当作该序列实现的一组无序耦合；不同序列改变耦合矩阵。）
  ◇ 局域外场 h_i(x) 与有效场 → 序列符号排列和位置索引对内部权重模式的偏置（位置身份、符号上下文作为单点场项进入同一能量函数，控制局部磁化或状态。）
  ◆ 读出块 B 的宏观磁化 m_B 或块响应 → 被远程影响的功能区域或执行单元的行为读数（远端功能行为被粗粒化为一个块宏观序参量；扰动引起的读数变化对应块磁化变化。）
  ◆ 磁化率/线性响应 χ_iB = ∂m_B/∂h_i，以及联合响应 → 扰动关键位置 i 后远端功能读数的变化标签（因果远程影响的一阶或联合近似；χ_iB 大意味着局部扰动可远程改变块 B，中介效应可通过条件响应剥离。）
  ◆ BP/TAP 消息与腔场；路径求和 → 中间可能经过若干中介位置（消息传递将直接耦合和经由中介的自旋链合成为有效远程响应，避免把直接相关误当因果。）
  ◇ 稀疏扰动实验中的少数自旋响应测量 → 已标注关键位置集合与功能变化标签（标签只覆盖少量自旋，作为稀疏监督或验证信号，不直接给出全部关键位置。）
  ◆ 淬火平均与实现间交叉验证 → 训练序列与评估序列相似造成的虚假性能（按序列实现分组而非按位置拆分，避免同一耦合实现泄漏；相似序列视为同一无序实现的近邻。）
  ◇ 高维逆伊辛中的 L1 正则与不可辨识性 → 正负样本极不平衡、关键位置占比低（稀疏先验对应少数关键位置；正则化控制过拟合和伪耦合。）

**常规骨架**：正则化伪似然逆伊辛：对每个输入序列，用 L1/L2 惩罚逻辑回归从内部成对影响权重和局域状态估计有效 J_ij(x) 与 h_i(x)；用按序列分组的交叉验证选正则强度。；BP/TAP 线性响应：在估计的 J,h 上跑信念传播或 TAP 方程，求边际 m_i 与协方差或磁化率矩阵；对远端读出块 B 计算 χ_iB = ∂m_B/∂h_i，用其绝对值或块整合值排序。；稀疏不平衡校准：用 PR-AUC 或 top-k recall 评估候选排序，并用保持度序列的符号置换或随机化零模型给出排序置信区间。
**非典型注入**：不把关键位置定义为平均磁化率最大，而定义为能使远端读出块 B 跨越 TAP 亚稳边界的局部场脉冲：用 B 块 TAP 自由能 Hessian 的最小特征值或软模方向，寻找单点扰动可使 B 落入另一吸引盆的位置；只做亚稳脆性排序，并与线性响应排序做消融。
