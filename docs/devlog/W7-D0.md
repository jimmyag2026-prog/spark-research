## 与设计稿的偏差（如实）

1. **`RawSink` 同步而非 async**：两个埋点在 finally/包装器返回路径，同步 append 让「记了没记」不依赖 promise 落定顺序。
2. **全局兜底 sink**：设计只写了项目内 `raw/`；实现里没有项目上下文的调用落 `<dataDir>/raw/`（project=null）。G1 对账两处合计。
3. **`quality` 列由 `deriveQuality(metadata)` 派生**，写入方不必再改一遍（V46 形状）；显式 `quality` 输入排前并去重。
4. **`provenanceClass` 缺省不拒绝**，走 `classForOrigin()` 兜底——但**源码门禁**要求生产写入点显式声明（18 处全部核）。拒绝会让测试与老库回填都要重写，收益不够。
5. **`createFromArtifact(artifact, extra)`** 接受 `extra.provenanceClass`（默认 derived）；review 草稿与 novelty 报告显式 model_generated。
6. **`raw/kernel` 不引用 execution_records**：那张表没有生产写入方（V82）。
7. `id` 用 randomUUID 不用 ulid（无依赖）；时序靠 `ts` + 文件内顺序。
8. 未做：`ext` 机制注册外部 RawSink（`config set rawSink`）——没有第二个实现之前不加只写不读的配置项（V40 教训）。
