## 与设计稿的偏差

1. **for-sharing 的 journal 打桩而非丢弃**（设计写「丢弃」）：丢会断链；打桩保 seq/prevHash/hash、patch 换骨架，导入侧对 stub 行只核链。
2. raw 行 `project` 字段导入后保持来源 slug（hash 覆盖它）。
3. `data import` 不做合并，只进空项目——它是验收对账与迁移工具，不是同步工具。
4. Parquet 不做（用户裁定）；DuckDB 示例走 `read_json_auto(..., union_by_name=true)`。
5. alpha 编号：D2 = alpha.4，三 lane 收口 = alpha.5。
