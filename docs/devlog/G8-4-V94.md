# G8-4 · V94 无价模型默认拒绝 + anthropic 单价表

**日期** 2026-09-11 · **分支** `fix/G4-V94-unpriced-gate` · **闸门** G-4

## 问题
预算闸用「已知成本下界」判超。单价表查不到的模型（本地端点、未登记的新模型）每次成本都"未知"，
下界永不推进，`--budget-usd` 对它形同虚设——闸静默失效。anthropic 六个 provider 之一却一条价都没有。

## 改动
- `backend/src/usage/ledger.ts`
  - `usageTrackingLlm`：设了 `budgetUsd` 且发前估价为 null（无单价）→ `kind:"budget"` 拒绝，消息给两条路（`--allow-unpriced` / `SPARK_LLM_PRICING_JSON` 补价）。
  - `allowUnpriced: true` 放行：调用照发，`UsageEntry.unpriced:true`（只在 true 时写），`UsageTotals.unpricedCalls` 计数。没设预算时不拦（闸不存在就没有"失效"），仍标 unpriced。
- `backend/src/cli/usage.ts`：unknown>0 时追加一行"其中 N 次是 --allow-unpriced 放行"。
- CLI 接线：`lit read` / `lit review` / `idea new` / `idea check` 新增 `--allow-unpriced`（帮助文本同步）。
- `backend/src/llm/providers/registry.ts`：anthropic 五条，2026-09-11 WebFetch 直读 `platform.claude.com/docs/en/about-claude/pricing`：Opus 5 $5/$25 · Sonnet 5 $2/$10（页面注明上市价已成标准价）· Haiku 4.5 $1/$5 · Sonnet 4.5 $3/$15 · Opus 4.5 $5/$25。注释记录 4.7+ 新 tokenizer 约多 30% token（字符启发式估价对其偏低）。
- `backend/src/llm/router.ts`：`PROVIDER_MODELS.anthropic` 更新为上述五个（新增 opus-5 / sonnet-5 / haiku-4-5-20251001，保留 4.5 两个别名）。
