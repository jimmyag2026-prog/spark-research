## 网络前提（硬前置，R6 与 A8 各测一次，写进报告首段）

```bash
for i in 1 2 3 4 5; do curl -s -o /dev/null -m 20 -w "%{time_connect}\n" https://openrouter.ai; done
```

中位数 < 1s 且最大 < 3s。**不达标不建基线**——记录五个数字，把该轮标为「网络不达标」，等达标再跑。
v0.9 之前没有交互链路的任何基线数字；**R6 建的就是基线**，坏网络上建的基线会让 DONE 第 2 条永远无法判定。

## R6 §基线 · 三个数（脚本 `scripts/measure-chat.ts`，W9-2 已入库并冻结：消息文本写死、`--dry-run` 只探网络与台账不花钱）

对每个课题项目跑 **同一条固定 chat 消息 × 5 轮**（消息文本写死在脚本里，跨版本不变）：

| 指标 | 怎么取 | 记法 |
|---|---|---|
| 墙钟 | 从 POST `/api/session/chat` 发出到 200 返回 | 每轮秒数，报 **P50 / P90**（5 轮取第 3 / 第 5 小） |
| 每轮模型调用次数 | 跑前后 `usage.jsonl` 行数差 | 每轮一个整数，报中位数与最大 |
| 失败占比与 errorKind | 新增行里 `ok:false` 的比例；`byErrorKind` | 比例 + 分布 |

脚本输出一张表进 `docs/devlog/R6.md`，**并把原始 usage.jsonl 片段附上**（数字要能被复核）。
每轮 chat 花费约 $0.0003–0.001，五课题 × 5 轮 ≈ $0.03，**预算上限 $0.30**，`--budget-usd` 强制。
