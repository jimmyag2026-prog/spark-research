# 可迁移方法目录

用途：阶段 ② 多语言唤醒的"系统穷举"辅助。当模型自发列出的领域不够远或不够多时，
把这份目录里的条目逐条问"这个方法是否适用于当前结构签名、为什么"。每条给出：
它处理的结构形状、来源领域、常见落地领域。

使用提示：
- 问"是否适用"时要求模型指出**哪条对应是承重的**，否则每条都"适用"
- 一条方法命中多个签名字段（对象 + 动力学 + 目标）比只命中一个更可能是真同构
- 目录不是封闭的：模型自己唤醒出目录外的领域是好事，只要它能写出映射表
