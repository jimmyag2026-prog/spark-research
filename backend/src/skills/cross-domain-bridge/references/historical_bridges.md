# 历史跨领域突破清单（回测基准）

用途：给 `cross-domain-bridge` 做历史回测。做法是把问题按"突破前"的语言写成问题卡，
只允许模型使用突破年份之前的知识（prompt 里声明截止年份），看管线能否在前 k 名里提出
真实发生过的那座桥。两个泄漏要防：预训练里已含答案（用改写过的问题陈述、换掉专有名词），
以及问题卡的写法暗示答案（术语表里不能出现目标领域的词）。
